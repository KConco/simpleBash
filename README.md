# Проект Simple Bash Utils

Этот проект представляет собой реализацию двух основных утилит командной строки, `cat` и `grep`, в рамках учебной программы Школы 21. Цель — воссоздать их базовую функциональность на языке C, чтобы глубже понять системное программирование и стандартные операции ввода-вывода.

## Используемые технологии

*   **Язык:** C (стандарт C11)
*   **Компилятор:** `gcc`
*   **Автоматизация сборки:** `make`
*   **Основные библиотеки:** `stdio.h`, `getopt.h`, `regex.h`

## Функциональность

### 1. s21_cat

Клон утилиты `cat` для объединения и отображения содержимого файлов.

**Поддерживаемые флаги:**

| Короткий | Длинный           | Описание                                                                 |
|----------|-------------------|--------------------------------------------------------------------------|
| `-b`     | `--number-nonblank` | Нумерует только непустые строки. Имеет приоритет над `-n`.               |
| `-n`     | `--number`          | Нумерует все строки вывода.                                              |
| `-s`     | `--squeeze-blank`   | Сжимает несколько смежных пустых строк в одну.                           |
| `-e`     |                   | Отображает `$` в конце каждой строки (эквивалентно `-vE`).               |
| `-E`     |                   | Отображает `$` в конце каждой строки.                                    |
| `-t`     |                   | Отображает символы табуляции как `^I` (эквивалентно `-vT`).              |
| `-T`     |                   | Отображает символы табуляции как `^I`.                                    |
| `-v`     |                   | Отображает непечатаемые символы с использованием нотации `^` и `M-`.      |

### 2. s21_grep

Клон утилиты `grep` для поиска текста по шаблонам.

**Поддерживаемые флаги:**

| Флаг | Описание                                                                    |
|------|-----------------------------------------------------------------------------|
| `-e` | Указывает шаблон для поиска.                                                |
| `-i` | Игнорирует регистр в шаблоне и входных файлах.                               |
| `-v` | Инвертирует поиск, выбирая строки, не соответствующие шаблону.               |
| `-c` | Выводит только количество совпадающих строк для каждого файла.               |
| `-l` | Выводит только имена файлов, содержащих совпадающие строки.                  |
| `-n` | Предваряет каждую строку вывода ее номером (начиная с 1).                    |

## Инструкция по сборке

Для сборки утилит перейдите в соответствующий каталог с исходным кодом и выполните команду `make`.

### Сборка s21_cat
```bash
cd src/cat
make
```
Эта команда создаст исполняемый файл `s21_cat` в каталоге `src/cat`.

### Сборка s21_grep
```bash
cd src/grep
make
```
Эта команда создаст исполняемый файл `s21_grep` в каталоге `src/grep`.

## Инструкция по использованию

После сборки вы можете запускать утилиты из их соответствующих каталогов.

### Примеры использования s21_cat

*   **Отобразить содержимое файла:**
    ```bash
    ./s21_cat my_file.txt
    ```

*   **Пронумеровать все строки в файле:**
    ```bash
    ./s21_cat -n my_file.txt
    ```

*   **Сжать пустые строки и пронумеровать непустые:**
    ```bash
    ./s21_cat -s -b my_file.txt
    ```

### Примеры использования s21_grep

*   **Найти все строки, содержащие "error", в лог-файле:**
    ```bash
    ./s21_grep "error" app.log
    ```

*   **Найти все строки, НЕ содержащие "success" (без учета регистра), и показать номера строк:**
    ```bash
    ./s21_grep -i -v -n "success" app.log
    ```

*   **Вывести имена файлов, содержащих слово "main":**
    ```bash
    ./s21_grep -l "main" *.c
    ```
